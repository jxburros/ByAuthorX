# ByAuthorX 0.4.3

## Changes

- Adopt the unified manual release process with complete verified artifacts.
- Require security-fixed Pillow 13 and refresh the certificate bundle.
- Temporarily disable the optional Docling add-on until upstream supports Pillow 13.
  The default pypdf reader remains available. Existing Docling libraries report an
  explicit error and can be switched back to pypdf without changing source documents.
- Report missing Linux font families accurately during EPUB export.
