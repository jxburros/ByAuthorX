# Internal integration contract

All code uses Python 3.11+, package src/byax. Public data is JSON-compatible dicts. No UI dependency in model/engine/storage/checks/providers/jobs/CLI except lazy rendering calls. ByaxError(code, message, **details) has to_dict() and exit_code.

## Document
new_document(title="Untitled", text="") -> dict from byax.model. JSON keys:
schema_version:1, id:doc_UUID, revision:rev_UUID, metadata:{title,author,language:"en"}, blocks:[...], styles:{...}, layout:{paper:"Letter",width:612,height:792,margins:{top:72,right:72,bottom:72,left:72}}, assets:{}, references:{}, profiles:{}, review:{comments:[],proposals:[],tracked_changes:[],findings:[]}, fields:{}, layers:[], history:{revisions:[],branches:{},current_branch:"main"}, requests:{}, settings:{}.
Block: {id, type:"paragraph"|"heading"|"table"|"image"|"page_break"|"section_break"|"toc"|"footnote", text:"", style:"body", marks:[], attrs:{}}. Heading attrs.level int. Paragraph attrs can hold list kind/level, alignment, spacing. Optional section_id. Marks:{start,end,type,value} scalar offsets. Table adds rows:[{id,cells:[{id,text,attrs:{}}]}], attrs.header_rows. Image attrs:{asset,alt,width,height,wrap,anchor}. Assets mapping sha256 -> {data: base64, mime,name}; storage writes bytes separately. Unknown data must not silently disappear.

## Core modules (engine agent owns model.py errors.py storage.py engine.py checks.py)
model.new_document; model.text_of(doc) -> str; model.iter_blocks(doc).
storage.load_document(path)->dict, save_document(doc,path, *, owner=None)->None; pack(source_dir,out_path), unpack(path,out_dir,include_history=False); DocumentLock(path, owner=None) context manager with acquire()/release(); storage handles atomic ZIP validation and file locks. Same owner allows GUI save. GUI holds lock for whole session; CLI should fail if locked.
engine.apply(doc, envelope, *, dry_run=False)-> (candidate_doc, result_dict). envelope expected_revision, request_id, operations, protect, required_suites. No file IO. Strict canonical ops and state checks. engine.inspect(doc, section=None, target=None, limit=100)->dict; engine.find(doc,query,case_sensitive=False,whole_word=False,regex=False)->dict; engine.context(doc,target=None,limit=10000,profile=None)->dict; engine.diff(doc,from_revision)->dict; engine.restore(doc,revision)->(doc,result); engine.checkpoint(doc,name)->(doc,result); engine.branch(doc,name)->(doc,result).
checks.run_checks(doc,suites=None,*,limit=100,profile=None)->dict with validation,findings,coverage,summary. Suites publication/structure/accessibility/editorial/requirements/print/spelling.
Minimum operations: insert_text(target,offset,text), replace_text(target,match,replacement,occurrence?,expected_text?), delete_text(target,start,end,expected_text?), set_text(target,text,expected_text?), insert_paragraph(after?,text,style?,id?), delete_block(target), move_block(target,after?), apply_style(target,style), format_text(target,start,end,marks), set_metadata(values), set_layout(values), insert_table(after?,rows,columns), update_cell(target,text,expected_text?), add_row(target,index?), remove_row(target,index), add_column/remove_column(target,index), add_comment(target,text), resolve_comment(target), add_reference(id,values), fill_fields(values), add_layer(values), update_layer(target,values), place_image(after?,asset,alt,width?,height?), set_attributes(target,values), protect(target,kind), propose(values), accept_proposal(target), reject_proposal(target). Engine agent can extend with announced exact contracts.
Result has schema_version,execution,validation,review,document_id,base_revision,revision,changed_ids,findings,coverage,outputs.

## Exchange/layout (formats agent owns exchange.py layout.py)
exchange.import_document(path)->(doc, report); exchange.export_document(doc,path,format=None,profile=None)->report. Support txt/md/html/docx/odt/rtf/doc; unsupported structure must produce losses not silent success. Native delegates storage. layout.build_document(doc)->QTextDocument (requires Qt app), layout.render(doc,out_dir,pages=None)->report; layout.export_pdf(doc,path,pages=None)->report. Shared Qt shaping/layout for GUI print view and export; layout.ensure_app() for headless. GUI may use build_document in QTextEdit but must map edits to canonical blocks. Rendering takes doc only, never executes imported code or loads unselected remote resources.

## Providers/jobs (provider agent owns providers.py jobs.py transcription.py)
providers.list_capabilities()->list; ProviderConfig dataclass alias,kind,model,endpoint?,credential_ref?,timeout=60; ProviderRegistry(config_dir=None) .list(), .save(config), .get(alias), .test(alias), .review(alias,text,*,context=None)->dict, .transcribe(alias,audio_path,*,language="en")->dict. Network only explicit method calls; no configured key assumed. OpenAI/Anthropic/Gemini/Ollama/ElevenLabs/whisper.cpp. Registry stores config locally excludes secrets; methods can return structured incomplete unsupported results.
jobs.JobManager(root=None) .submit(kind,payload,worker)->job dict; worker(payload,cancel_event), .status(id), .result(id), .cancel(id), .list(), .recover(id). Jobs persistent; input revision frozen. transcription processing/insertion proposals revalidate revisions.

## CLI/MCP (CLI agent owns cli.py mcp.py service.py)
Argparse commands and stdio JSON-RPC MCP call common engine/storage/exchange/providers. JSON stdout only; structured errors and specified exit statuses; no shell execution except explicitly configured adapter. Optional REST disabled default, loopback filesystem scoped. Don't assume live services. Calls may need to adapt once core modules land.

## GUI (GUI agent owns gui.py gui_*.py)
Qt native QMainWindow editor; menu and ribbon-like compact toolbar, outline, inspector/review dock, status; use common model/engine and layout where possible. Lock open files, autosave recovery, external change detection, undo/redo/history, native dialogs/printing. UI remains responsive, providers via threads. No web interface.
